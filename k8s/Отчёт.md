## Абстракции Kubernetes

| Абстракция | Манифест | Назначение |
|---|---|---|
| Namespace `link-tracker` | `00-namespace.yaml` | Изолирует все объекты приложения, удаляется одной командой |
| ConfigMap `link-tracker-config` | `01-configmap.yaml` | Несекретная конфигурация: имя БД и пользователя, параметры планировщика, адрес прослушивания |
| Secret `link-tracker-secret` | `02-secret.yaml` | Пароль БД и токены GitHub/StackOverflow |
| StatefulSet `postgres` | `10-postgres.yaml` | Запускает PostgreSQL|
| Service `postgres` | `10-postgres.yaml` | Стабильное DNS-имя базы данных внутри кластера |
| Deployment `scrapper` | `20-scrapper.yaml` | Запускает приложение, масштабируется командой `kubectl scale` |
| initContainer `wait-for-postgres` | `20-scrapper.yaml` | Откладывает запуск приложения до готовности базы |
| Service `scrapper` (NodePort 30081) | `20-scrapper.yaml` | Доступ к приложению снаружи кластера и распределение запросов между репликами |

## Взаимодействие сервисов


- **Браузер -> scrapper** Браузер обращается по HTTP к сервису `scrapper` (NodePort). Он отдаёт и страницу, и API, и распределяет запросы между подами.
- **scrapper -> PostgreSQL** Приложение находит базу по имени `postgres:5432`. Пароль и настройки берутся из ConfigMap и Secret.
- **scrapper -> GitHub/StackOverflow** Раз в заданный интервал каждый под проверяет ссылки через внешние API.
- **Реплики между собой** Напрямую не общаются, всё общее лежит в PostgreSQL. Событие по ссылке обрабатывает только одна реплика, поэтому уведомления не дублируются.
- **Уведомления** Приложение записывает их в таблицу `updates`, а интерфейс раз в 5 секунд запрашивает новые.
